# Should an AI-focused fund lead Truna's $15M seed?

A single self-contained page holding the whole study: the verdict, how the
decision space was covered, the questions the investment turns on, every
alternative company shape the search enumerated, and each of the items and
connections behind them — browsable and mapped in 3D.

Read it: **https://shivaconverge.github.io/truna-venture-study/**

The page needs no server. `index.html` carries its own styles, script and data,
so opening the file directly works exactly as well as the hosted copy.

This repository is public only because GitHub Pages requires it. The page is
marked `noindex` and `robots.txt` disallows crawling, so it is meant to be read
by whoever is sent the link rather than found through a search engine.

Generated by `viz/build_dashboard.py` in the private harness repository; the
run artifacts it reads are not published here.
